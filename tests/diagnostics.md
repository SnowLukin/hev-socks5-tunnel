# Проверки диагностики сессий

`make test-diagnostics` собирает настоящий tunnel, core, lwIP и task runtime,
затем запускает TCP- и UDP-сценарии на локальных сокетах. Требуются C-компилятор
и инициализированные submodules. Тесты читают JSONL-файлы штатной истории при INFO.

TCP: reset с исходным кодом lwIP, ошибки read/write, обычный EOF и отмена.
Полный splice проверяет timeout передачи и ожидания ACK; callback штатного
закрытия не пишет failure.
UDP: назначение первого кадра до подключения к proxy, тихий поток кадров,
реальный SOCKS5 handshake и закрытие control-соединения локальным proxy,
ошибка и закрытие control-сокета, отмена. После handshake диагностика всей
ассоциации использует `udp-association`: она может обслуживать несколько адресов.
На старой Android-базе проверяется продолжение второй coroutine после временного
таймаута без подмены следующей ошибки на timeout.

Тесты используют внутренние callbacks из production-исходников без расширения
API для тестов. Они проверяют запись диагностики и её доставку в историю;
проверки реального VPN на Android, iOS и macOS остаются отдельным этапом.
